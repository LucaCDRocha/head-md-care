# User Tests 02 (05.06.26)


## Observations: Misunderstandings / Pain Points

**Scene: Inside the café, amphora**<br>
If all broken shards are immediately visible, users tend to focus on repairing the amphora as quickly as possible instead of exploring the objects on the shelf and engaging with their individual stories in between. The shards should therefore appear one by one. For example, when zooming in on an object, the perspective could shift to reveal the next one.

<br>

**Next step:**<br>
Create a first version with narrated audio stories. To quickly prototype this, AI-generated voices could be used.
