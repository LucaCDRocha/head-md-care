# PressKit

This directory contains assets for press and promotional use related to the "Ooops!" project.

## Assets

All the final assets are organized in the subfolder named `2026-06-17-Final/`. Inside this folder, you can find:

- **Images** on the `images/` subdirectory.
- **PDF presentation** files at the root of the `2026-06-17-Final/` folder.
- **Video** is available at this link: [Ooops! Video](https://youtu.be/mGMisrteinw).
